# Bergbahn-Bauer

Ein 3D-Skigebiet-Baukasten im Browser. Lifte bauen, Pisten präparieren, Häuser und Werbung platzieren.

Spielen: https://c6n5td2k4f-bit.github.io/bergbahn-bauer/

Bauen: `npm install` und dann `node build.mjs`. Das erzeugt `dist/index.html`, die als `index.html` hier im Hauptordner liegt.
